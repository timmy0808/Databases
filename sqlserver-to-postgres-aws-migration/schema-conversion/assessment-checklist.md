# Assessment checklist

- Inventory tables, columns, keys, constraints, indexes, views, procedures, functions, triggers, jobs, and integrations.
- Record source version, edition, database size, transaction rate, growth, and downtime tolerance.
- Identify unsupported T-SQL, CLR objects, linked servers, SSIS packages, SQL Agent jobs, full-text search, XML, spatial types, and large objects.
- Classify every object as automatic, minor remediation, manual conversion, redesign, or retire.
- Verify every CDC table has a primary or suitable unique key.
- Measure long-running transactions and transaction-log retention.
- Define precision, timezone, JSON, audit, and clinical business validation rules.
- Benchmark full-load throughput and CDC latency with production-like volume.
